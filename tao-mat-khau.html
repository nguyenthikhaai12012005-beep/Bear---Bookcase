Tạo mã mật khẩu cho “Kệ sách của tôi”

Nhập mật khẩu bạn muốn dùng. Trang sẽ đổi nó thành một mã (SHA-256). Bạn chỉ lưu mã này lên GitHub, không lưu mật khẩu thật. Việc tính mã diễn ra ngay trên máy bạn, không gửi đi đâu.

Mã sẽ hiện ở đây.
  1. Mở file sach/cau-hinh.js (trên máy bằng Notepad, hoặc trên GitHub bấm biểu tượng bút chì).
  2. Thay dòng window.KE_SACH_MAT_KHAU = ""; bằng dòng ở trên (nút “Sao chép dòng mã”).
  3. Lưu file (trên GitHub: bấm Commit changes, khoảng 1 phút sau có hiệu lực). Kệ sách sẽ hỏi mật khẩu.
  4. Muốn bỏ mật khẩu: để lại window.KE_SACH_MAT_KHAU = "";

Mật khẩu này chỉ chặn người xem thông thường trên trang. Website tĩnh vẫn công khai: ai biết đường dẫn trực tiếp tới file PDF trong thư mục sach/ vẫn tải được, và repository GitHub công khai thì ai cũng xem được các file.
